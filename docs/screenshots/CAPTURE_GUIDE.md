# Roteiro de captura de screenshots (sem PII)

**Demo canônica atual:** https://public-data-quality-auditor-br-nu.vercel.app

1. Abrir home — confirmar CTA "Rodar demo" + "Ver limitações" (lab).
2. `/audit` — quatro cards (3 sintéticos + IBGE).
3. Auditar **Municípios BR** — aba Resumo (score 87.4 + critical/high).
4. Aba **Issues** — filtros + `duplicate_id` / UTF-8 "São Paulo".
5. Aba **Colunas** — profiling.
6. Aba **Dicionário** — campos sugeridos.
7. Exportar Markdown / datapackage (opcional).

Arquivos em `assets/screenshots/`:
- `01-audit-summary.png` (captura real 2026-07-13)
- `02-issues-register.png` (captura real 2026-07-13)
- `01–04 *.jpg` (mockups anteriores; preferir PNG reais quando disponíveis)

Não incluir dados pessoais. Demos são sintéticos ou amostra pública sem PII.
